# h5

## https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F

- Git on jakautunut versionhallinta, kaikki historia omalla koneella

- Tallentaa projektin snapshotteina

- Toimii nopeasti, koska useimmat komennot ovat paikallisia

- Käyttää SHA-1 tarkisteita varmistaakseen tiedon eheyden 

  ## Git komennot

- "git add ." lisää kaikki muutokset staging-alueelle
  
- "git commit" tallentaa muutokset paikalliseen historiaan
  
- "git pull" hakee ja yhdistää etävaraston uusimman version
  
- "git push" lähettää omat commitit varastoon

- Käytännössä Gitin perus workflow

  ## suolax repon loki

- git log --patch näyttää commitit ja tarkat muutokset, kuten teron lokeista huomaa

- Näkee tekijän nimen, sähköpostin ja aikaleiman
  
- Voi seurata projektin kehitystä ja virheitä

- Lokin lukeminen on paras tapa ymmärtää koko projektin historia
